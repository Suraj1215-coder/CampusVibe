# ⚡ CampusVibe — College Club Event Management Website

CampusVibe is a modern, responsive web application for exploring, registering, and managing college club events. Built with clean light theme aesthetics, floating 3D/hover animated cards, student registration tracking, and a full-featured admin management console.

---

## 🌟 Key Features

### 🎓 Student / User Experience
- **Home Page**: Interactive hero section, club introduction, featured spotlight event, and dynamic stats counter.
- **Floating Event Cards**: Levitation animations and rich micro-interactions for event details (Name, Date & Time, Venue, Description, Category).
- **Search & Category Filters**: Search events in real-time by keyword or filter by category (*Technology, Cultural, Sports, Workshop, Arts, Academic*).
- **Event Registration**: Complete registration form with validation (Name, Email, College, Academic Year, Phone).
- **My Registrations & Cancellation**: Dedicated "My Registrations" view allowing students to view their registered events and cancel/withdraw registration anytime with 1-click confirmation.
- **Fully Responsive**: Mobile-first fluid layout optimized for phones, tablets, and desktop displays.

### 🔐 Admin Management Console (Credentials: `admin` / `admin123`)
- **Dashboard Stats**: Real-time counters for Total Events, Registrations, Categories, and Featured Events.
- **Add / Edit Event**: Modal dialog to publish new events or modify existing event details.
- **Delete Event**: Safe removal with registration impact warning.
- **Manage Registrations**: View, filter, and remove student registrations.

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Suraj1215-coder/CampusVibe.git
   cd CampusVibe
   ```

2. Open `index.html` directly in any web browser, OR serve via local HTTP server:
   ```bash
   npx http-server . -p 8080
   ```

3. Visit `http://localhost:8080` in your browser!
